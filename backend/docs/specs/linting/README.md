# Linting Specification Index

This directory contains baseline linting specifications and policy templates.

## Documents

- `baseline.md`: cross-language linting principles and required policy fields.
- `python.md`: Python-specific linting baseline and recommended tool profile.
- `exceptions.md`: standardized exception process and record template.
- `typed_boundaries.md`: API-boundary typing requirements for inbound payloads.

## Usage

- Reference these specs from domain specs when introducing or changing lint rules.
- Keep tool choice flexible, but preserve policy outcomes and review gates.
